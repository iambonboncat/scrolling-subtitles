# 在线手持全屏滚动字幕

#### 介绍
- 支持全屏、滚动字幕、固定字幕，含有各种特效绚丽的样式，可自由搭配样式，让你成为全场最靓的仔。
- 适用于搭讪、机场接机、接人、演唱会、寻人、赛场助威、地铁搭讪等等

#### 功能
- 1.实现多方面的自由搭配，可以根据自己的审美搭配出好看的样式。
- 2.附带下载和上传功能，这样搭配好后，就可以下载下来，等下一次把文件再上传上去，就不需要再重复设置了。

#### 使用要求
- 1.页面样式主要趋向于手机端，电脑端也是可以用的。
- 2.里面有些样式可能会很耗性能，需要保证你的设备性能不是那么糟糕。
- 3.需要较新的浏览器，老的浏览器可能会没有动画的执行

#### 问题说明
- 对于下载功能，微信处于安全考虑，可能是不支持下载的，如果你想要使用下载功能可能需要在浏览器打开。

## V2 优化说明

本分支在原项目基础上进行了轻量增强，尽量保留原有页面和交互：

- 字幕内容通过 DOM 节点和 `textContent` 生成，避免把用户输入作为 HTML 解析。
- 保留输入中的空格。
- 配置在浏览器本地自动保存并尝试在下次打开时恢复（不上传服务器）。
- 上传配置文件限制为 2MB，并对解析异常进行提示。
- 下载文件后延迟清理 Blob URL，减少临时资源泄漏。
- 已对项目 JavaScript 文件进行 Node.js 语法检查。

自动保存仅存储在当前浏览器的 localStorage；清除浏览器数据或换设备后不会同步。


## V3 体验升级

- 播放时显示轻量浮动控制栏：暂停/继续、方向反转、速度滑块、隐藏控制栏、退出。
- 控制栏隐藏后，点击字幕区域可重新显示。
- 通过屏幕常亮 API 尝试保持设备显示开启（浏览器或系统不支持时会自动降级）。
- 支持横竖屏变化时调整字幕显示，并保留原有沉浸式/全屏逻辑。
- 空格键暂停/继续，方向上/下键调节速度，Esc 退出（桌面端）。

部分手机浏览器的屏幕常亮和原生全屏能力受系统限制。
